# v0.3 Architecture

`Legacy Directive -> TrackPlan Parser -> Locked Content Layer + Recomputable Music Layer -> Master Profile -> Market Recipe -> Compiler -> QA`

## Locked Content Layer
- story source / episode boundary
- story act / story role
- scene / listenerSituation / emotionArc
- title / hook
- track order

## Recomputable Music Layer
- BPM
- dominant genre + one tint
- recurring vocal fingerprint
- Core / Memory / Anchor
- section structure
- track-level performance behavior

## Conflict rule
`Latest user brief > Structured Track Plan > trusted legacy story/history > current master > market/channel rules > reference DNA > public rules > stale legacy music rules`
